01

Prerequisites

Use Node.js 24+, API credit and a supported model. Windows may require Git Bash. The lesson uses fictional local helpdesk data: no real support account, email service, GitHub token or Managed Agents IDs are required.

node --version
npm --version
02

Install and create .env

Preserve an existing .env. Enter your own API key privately; inherited shell variables take precedence. The npm scripts load the file when Node starts. Never publish the real .env.

cd .\agent-sdk\lesson53-support-triage
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal open, open the five student pages and choose an experiment. Reuse an existing instance or change PORT and restart if a different process occupies the port.

npm start
# http://127.0.0.1:3153
04

Review a real pending draft

Choose Approve, Edit or Reject and click Run. The real SDK reads the ticket and history, then tags it. When paused, inspect the draft and recorded-replies-before count. Click Approve, change the text and click Edit and approve, or click Reject. The mode name does not automatically approve anything.

npm run sample:env -- approve
# Terminal sample also asks a/e/r before recording a reply.
05

Compare errors and structured data

Missing reads T-404 and must stop without mutation. History error is a controlled local fixture failure; the draft must not invent history. Structured requests a schema-validated summary after the actual approval outcome.

npm run sample:env -- missing
npm run sample:env -- historyerror
npm run sample:env -- structured
06

Inspect batch, limits and audit

Batch runs two fresh queries and needs two explicit decisions. Turn limit preserves a native error_max_turns. Audit displays actual PostToolUse responses. Each run retains helpdesk.json and audit.json under the ignored .runtime/runs/ folder. Read this local record; it is not proof of real email delivery.

npm run sample:env -- batch
npm run sample:env -- turnlimit
npm run sample:env -- audit
npm test
